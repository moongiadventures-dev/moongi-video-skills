# sfx-gen — 원하는 효과음을 실제 파일로

말로 된 요구("문 닫히는 묵직한 소리")를 **SFX 프롬프트 문법**으로 다시 쓰고, ElevenLabs로 오디오를
뽑아 후처리까지 끝낸다. 영상 모델(Seedance 등)이 화면과 함께 뱉는 사운드와 달리 **독립된 오디오
파일**이 나오므로, 이미 찍은 릴스·영상·게임·웹 인터랙션 어디에나 붙일 수 있다.

## 순서

1. **뭘 만드는지 한 줄로 확정.** 모호하면 딱 하나만 물어본다 (무슨 소리인지 / 몇 초인지).
2. **프롬프트를 다시 쓴다.** `references/prompt-book.md`의 공식과 카테고리 표를 따른다. 사용자가 준
   한국어 설명을 그대로 번역하지 말고, 음원·재질·동작·공간·감쇠로 분해해 영어로 재작성한다.
3. **비용을 먼저 말하고 승인받는다.** "N개 × M초 생성함, ElevenLabs 크레딧 차감됨. 갈까?"
   승인 없이 생성하지 않는다. `--dry-run`으로 프롬프트만 먼저 보여줄 수 있다.
4. **생성한다.** 기본 `--count 3` (같은 프롬프트의 변형 3개 → 고르게).
5. **결과를 보고한다.** 파일 경로 + 각 파일의 실제 길이/피크. 오디오를 컨텍스트로 읽지 말고
   경로만 알려준다.

## 실행

```bash
python "D:/Claude - od/Skills/video-production/sfx-gen/gen.py" \
  --prompt "<재작성한 영어 프롬프트>" \
  --out "<저장 폴더>" \
  --name "<파일 슬러그>" \
  --count 3 \
  --duration 1.2
```

주요 플래그:

| 플래그 | 뜻 |
|---|---|
| `--count 1-4` | 변형 개수 (기본 3) |
| `--duration 0.5-30` | 초. **생략하면 모델이 알아서 정함** — 원샷은 생략이 더 자연스러울 때가 많다 |
| `--influence 0-1` | 프롬프트 충실도. 기본 0.3(자연스러움·다양성), 0.6–0.8(지시대로) |
| `--loop` | 심리스 루프. 앰비언스 전용. **후처리를 자동으로 끈다**(이음매 보존) |
| `--no-post` | 트림·정규화 끄기 (원본 그대로) |
| `--dry-run` | 프롬프트·파라미터만 출력, API 호출 없음 |

출력: `<out>/<name>-1.mp3` … + `<out>/<name>.json`(프롬프트·파라미터·길이·피크 기록).

## 지켜야 할 것

- **한 파일에 소리 하나.** "문 닫히고 발소리"는 두 번 생성해서 섞는다. 한 프롬프트에 두 사건을
  넣으면 둘 다 뭉개진다.
- **음악 단어 금지.** `cinematic`, `epic`, `trailer`, `soundtrack`은 배경음악을 불러온다.
  프롬프트 끝에 `no music, no melody`를 붙인다.
- **루프는 후처리하지 않는다.** 앞뒤를 트림하면 이음매가 깨진다. `--loop`가 알아서 끈다.
- **프로 사운드는 레이어다.** 묵직한 임팩트 하나가 필요하면 `impact` + `low tail` + `air`를 각각
  뽑아서 겹치는 게, 한 번에 "묵직한 임팩트" 뽑는 것보다 거의 항상 낫다.
- 유료 생성이므로 **개수 말하고 승인받기**. 재생성도 마찬가지.

## 키
