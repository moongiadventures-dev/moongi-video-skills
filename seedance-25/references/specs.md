# Seedance 2.5 스펙 — 입력 한계 · 모드 · 파라미터

프롬프트를 짜기 전에 여기 한계 안에 들어오는지 확인한다. 넘으면 프롬프트가 아무리 좋아도 안 돈다.

공식 사이트: https://dreamina.capcut.com/ai-tool/home

---

## 1. 생성 파라미터

| 항목 | 2.0 | **2.5** |
|---|---|---|
| 생성 길이 | 4~15초 (97~361 프레임) | **4~30초** (97~721 프레임) |
| Long Video 모드 | 없음 | **30~180초 한 방에** |
| 연장(Extend) | 없음 | 원본 30초 이내면 4~30초 연장. 중첩 가능 → **누적 최대 60초** |
| 출력 해상도 | — | **480p, 720p** |
| 오디오만 입력 | 불가 (이미지/영상 중 하나는 필수) | **가능** |

> 해상도가 480p/720p뿐이다. 4K 납품이 필요하면 후처리 업스케일을 전제로 잡아라.

---

## 2. 입력 소재 한계

| 종류 | 2.0 | **2.5** | 포맷·규격 |
|---|---|---|---|
| 이미지 | 최대 9장 | **최대 30장 (4K까지)** | jpeg/png/webp/bmp/tiff/gif/heic/heif · 종횡비 0.4~2.5 · 변 300~6000px · 장당 30MB 미만 |
| 영상 | 최대 3개, 개당 2~15초, 총 15초 | **최대 10개, 개당 2~30초, 총 30초** | mp4/mov · 480p~4K · 개당 200MB 이하 · 24~60fps · 종횡비 0.4~2.5 · 총 픽셀 409,600~8,295,044 |
| 오디오 | 최대 3개, 개당 2~15초, 총 15초 | **최대 10개, 개당 2~30초, 총 30초** | wav/mp3 · 개당 15MB 이하 |

- 요청 바디 전체 64MB 이하. 큰 파일은 Base64로 넣지 마라.
- 실제 허용 구간은 살짝 여유가 있다: 영상·오디오 개당 1.8~30.2초, 총 30.2초.

---

## 3. 안정성 권장치 (공식 권고 — 넘으면 "뽑기")

| 항목 | 안정 구간 | 도전 구간 (불안정) |
|---|---|---|
| 오디오·영상 레퍼런스의 주체 수 | **1~5** | 6~10 |
| 오디오·영상 레퍼런스 길이 | **5~10초** | 그 이상 |
| 주체 이미지의 주체 수 | **1~8** | 9~12 |
| 편집할 영상 길이 | **20초 이내** | 그 이상 |
| 영상 편집용 레퍼런스 이미지 수 | **1~5장** | 6~8장 |

**다시점 소재:** 주체가 5개 이하면 단일 시점·다중 시점 둘 다 OK. 5개 초과면 단일 시점이 안정적이다.
여러 각도를 넣어야 하면 **한 장에 여러 각도를 몰아넣지 말고 각도별로 이미지를 나눠서** 올려라.
(안정성: 여러 장 × 여러 시점 > 한 장 안에 여러 시점)

## 4. 모드

| 모드 | 뭘 하나 | UI 위치 |
|---|---|---|
| **Omni Reference** (기본) | 텍스트 + 이미지/영상/오디오 레퍼런스로 새 영상 생성 | 모드 드롭다운 기본값 |
| **First and last Frames** | 첫 프레임 / 첫·끝 프레임 지정 | 모드 드롭다운 |
| **Long Video** | 30~180초 한 방에. 시계 아이콘으로 길이 슬라이드 | 모드 드롭다운 (2.5 신규) |
| **Smart Edit** | 영상 업로드 후 텍스트로 부분 편집 | 모드 드롭다운 (2.5 신규) |
| **Edit with marks** | 업로드 영상에 박스·화살표·앵커 마킹 + 텍스트 | 영상 업로드하면 입력창에 활성화 |
| **Edit Video** | 이미 생성된 영상에 같은 마킹 편집 | 생성 결과물 아래 아이콘 |
| **Extend Video** | 30초 이내 결과물 뒤에 4~30초 이어 생성 | 생성 결과물 아래 아이콘 |
| **Clay Renderer** | Maya/Blender 플러그인으로 화이트모델 export → 렌더 | 별도 플러그인 |

**기본 세팅 순서:** [AI Video] → [Dreamina Seedance 2.5] → 비율/해상도/길이 → 모드 선택 → 프롬프트 → 생성.

## 5. 언어

- **최적화 1순위:** 중국어, 영어, 스페인어, 인도네시아어, 말레이어
- **전면 지원:** 태국어, 아랍어, 포르투갈어, 베트남어, 일본어, **한국어**
- 대사는 **말하게 할 언어 그대로** 쓴다. 2.5는 한국어 대사를 한국어 발음·립싱크로 정확히 뽑는다(2.0은 영어가 섞여 나왔다).
- 묘사·통제문은 영어로 쓰는 게 안전하다. 대사만 한국어로 남긴다.

## 6. 2.5에서 새로 되는 것 (프롬프트로 부를 수 있는 능력)

| 능력 | 부르는 말 |
|---|---|
| 타임스탬프 초 단위 통제 | `0s-3s:` 형식 구간 명시 |
| 자막·BGM 안 붙이기 | `pure video, no subtitles, no background music` |
| BGM만 제거하고 목소리·자막 유지 | `remove background music, keep only character dialogue` |
| 크리에이티브 전이(카메라 언어·감정·"바이럴 감성"까지) | `@video1`을 참조하며 옮길 본질을 서술 |
| 부분 제거·교체 | 브러시/박스 + `erase / replace ... with ...` |
| 공간 시점 변경 (화면 밖 디테일까지 추론 보완) | `change the eye-level shot to a high overhead shot...` |
| 음색 레퍼런스 | 오디오 업로드 + `@audio1` |
| 다인물 독립 (쌍둥이·얼굴바뀜 방지) | 인물별 이미지 + 명시적 바인딩 |
| 그린스크린 편집 | 그린스크린 영상 업로드 + 새 배경 서술 |
| 화이트모델 통제 | Clay Renderer 플러그인 영상 업로드 |
| 두 영상 심리스 연결 | 영상 2개 업로드 + 연결 요청 |
| 멀티그리드 스토리보드 | 선화/졸라맨 스토리보드 이미지 업로드 |
| 리얼 질감 (AI티 제거) | `native skin texture`, `hair roots distinct`, `retaining true micro pores` |
| 롱테일 복잡 동작 | 복잡한 동작을 물리적으로 상세히 서술 |
